# بريد عرجون — تصميم الواجهات

معاينة عربية تفاعلية بـ Next.js وTypeScript وأيقونات lucide-react، مع دعم RTL والهاتف.

## خطة تنفيذ المشروع كاملة

راجع [خطة التنفيذ الكاملة](IMPLEMENTATION_PLAN.md) للمتطلبات المعتمدة والمهارات والمراحل ومعايير القبول وحالة الإنجاز والفجوات المتبقية. الواجهات الحالية معاينة محلية؛ يوضح ملف الخطة ما يلزم لتحويلها إلى نظام يعمل فعليًا.

## التشغيل

```sh
npm install
npm run dev -- --port 3108 --hostname 127.0.0.1
```

افتح http://127.0.0.1:3108

## الشاشات

- الموقع: الرئيسية، الخدمات، تفاصيل الخدمة ونموذج الطلب، نجاح الإرسال، المتابعة، التواصل، عن المنصة، الخصوصية والشروط.
- الإدارة: ملخص الطلبات والبحث والتصفية، تفاصيل الطلب، الملاحظات العامة والداخلية، السعر والدفع وسجل التعديلات.
- الخدمات: إضافة وتحرير وإخفاء ونشر، مجالات مرنة، اختيار الأيقونة واللون، محرر الحقول المطلوبة والاختيارية.
- الرسائل: صندوق وارد مع بحث وتصفية وحالات معالجة وملاحظات داخلية.
- المحتوى: نصوص الرئيسية، الأسئلة الشائعة، تعريف المنصة، صفحات مخصصة، ومعاينة نتيجة البحث.
- الإعدادات: الاسم والعبارة التعريفية والتواصل وزر WhatsApp وإعدادات توضيحية للبريد والتخزين.
- الفريق: إضافة أعضاء تجريبيين واختيار الأدوار والحالة.
- دخول الإدارة: شاشة تصميم دون مصادقة حقيقية.

## جولة سريعة

1. افتح /#admin ثم «الخدمات والمجالات».
2. أضف خدمة وحقولها وانشرها من تبويب «العرض والنشر».
3. افتح الموقع وقدم طلبًا ببيانات وهمية فقط، ثم احتفظ برقمه.
4. افتح الطلب في الإدارة، حدّث الحالة والملاحظة العامة واحفظ.
5. أدخل الرقم في /#tracking لمشاهدة التحديث.
6. يمكن أيضًا تجربة الرقم ARJ-8K4M2.
7. نموذج التواصل يحفظ رسالة في صندوق الإدارة المحلي.

## حدود المعاينة

كل البيانات التجريبية محفوظة في localStorage داخل هذا المتصفح وعلى هذا المنفذ. ليست تخزينًا آمنًا أو دائمًا. لا تستخدم بيانات شخصية أو كلمات مرور فعلية. الأدوار وأزرار الدخول للعرض فقط، ولا تطبق صلاحيات أمنية. لا توجد خلفية Django أو PostgreSQL بعد. لا تُرسل رسائل بريد أو WhatsApp ولا تُرفع المرفقات. إعدادات التخزين والبريد وSEO تصورات للواجهة وليست خدمات تشغيلية. الصفحات القانونية مسودات توضيحية. الخط العربي يُحمّل من Google Fonts مع خطوط بديلة.

## البناء

```sh
npm run build
npm run start -- --port 3107 --hostname 127.0.0.1
```

بيئة التطوير تستخدم .next-dev والبناء يستخدم .next لتجنب تداخل المعاينتين.

## إضافات استوديو الإدارة

- مكتبة الوسائط مع صورتين SVG محليتين للهوية والغلاف، وإضافة صور عامة PNG/JPG/WebP إلى المتصفح بحد 500 KB للصورة وأربع صور مضافة.
- اختيار صورة الخدمة والشعار وصورة المقدمة من مكتبة الوسائط.
- تنظيم أقسام الرئيسية وإظهارها أو إخفاؤها، وتعديل روابط التنقل وترتيبها.
- إضافة حالات الطلب وترتيب خياراتها مع الحفاظ على الحالات القديمة.
- قائمة تنبيهات محلية مرتبطة بالطلبات والرسائل الجديدة.
- نوافذ تحرير الخدمة والطلب تدعم Escape وحصر تنقل لوحة المفاتيح وإعادة التركيز.

نجح بناء الإنتاج وفحص TypeScript. جرى التحقق في المتصفح من محرر الخدمات، حفظ ملاحظة داخلية، محرر المحتوى، صندوق الرسائل، إخفاء قسم الأسئلة الشائعة من الموقع ثم استعادته، وعرض مكتبة الوسائط على شاشة ضيقة دون تجاوز أفقي. لا تعادل هذه الفحوص اختبار نظام خلفي أو صلاحيات حقيقية.
